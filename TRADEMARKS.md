# Política de marca FundoSmart

El código y los recursos incluidos en este repositorio se distribuyen bajo [AGPL-3.0-only](LICENSE). Esa licencia de copyright no concede derechos para usar las marcas **FundoSmart**, sus logotipos o nombres de dominio de una forma que sugiera que un fork, servicio o empresa es oficial, está certificado o cuenta con respaldo del proyecto.

Puedes usar el nombre para referirte verazmente al proyecto, indicar compatibilidad, enlazar al repositorio y explicar que tu trabajo deriva de FundoSmart. También puedes conservar avisos y atribuciones exigidos por la licencia.

Si distribuyes un producto o servicio modificado:

- deja claro que es un fork independiente;
- no uses el logotipo como identidad principal ni un nombre confundible;
- no uses `fundosmart.com` ni apariencias que impliquen acceso a FundoSmart Cloud;
- conserva la atribución y ofrece el código fuente correspondiente según AGPL.

Se permite mostrar capturas o el logotipo con fines informativos, educativos y de prensa siempre que no exista confusión sobre el origen. Para un uso comercial de marca, certificación o colaboración oficial, solicita permiso a `soporte@fundosmart.com`.

Esta política limita marcas, no las libertades otorgadas sobre el código por la licencia open source.
