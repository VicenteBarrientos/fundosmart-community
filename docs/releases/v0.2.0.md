# FundoSmart Community v0.2.0

Esta versión fortalece la instalación comunitaria y su cadena de publicación sin desplegar ninguna instancia de Cloudflare.

## Cambios principales

- Gate de autoalojamiento ligado al repositorio, cuenta, Worker, entorno y SHA completos seleccionados por la instalación.
- Manifiesto estricto de bindings y capacidades, parser canónico de archivos de entorno y allowlist de comandos Wrangler.
- Atestación local del artefacto Worker, migraciones y entradas del gate antes de una publicación administrada por cada instalación.
- Workspaces efímeros construidos desde los objetos del commit exacto, con publicación transaccional de `dist` y recuperación segura.
- Compatibilidad de los ensayos de recuperación con rutas largas de Windows y conservación del modo ejecutable en fixtures POSIX.
- Autenticación Wrangler aislada mediante API token acotado, sin reutilizar perfiles OAuth invisibles para el runtime privado.
- Workflow de release comunitario con source archive reproducible, CycloneDX, SHA-256, provenance SLSA e inmutabilidad de GitHub.

## Artefactos

- `fundosmart-community-v0.2.0.tar.gz`
- `fundosmart-community-v0.2.0.cdx.json`
- `SHA256SUMS`

Cada archivo queda sujeto a atestación de procedencia. El SBOM queda además vinculado criptográficamente al tarball de código fuente.

## Actualización

Lee primero la [guía de autoalojamiento](../operacion/autoalojamiento.md) y conserva respaldos externos antes de aplicar migraciones en una instalación propia. La publicación de esta versión en GitHub no despliega Workers, no ejecuta migraciones remotas y no modifica recursos Cloudflare de ninguna instalación.
