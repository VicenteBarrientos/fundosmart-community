# Código de conducta

FundoSmart quiere una comunidad útil, segura y acogedora para productores, desarrolladores, investigadores y empresas de toda Latinoamérica.

## Conducta esperada

- Trata a las personas con respeto, paciencia y buena fe.
- Critica ideas y cambios con evidencia, sin ataques personales.
- Usa lenguaje inclusivo y considera diferencias de idioma, experiencia, conectividad y contexto rural.
- Protege la privacidad: no publiques datos agrícolas, personales o comerciales de terceros.
- Declara conflictos de interés cuando una propuesta beneficie a un proveedor, cliente o producto propio.
- Acepta decisiones de moderación y ayuda a reparar el daño cuando corresponda.

## Conducta inaceptable

No se toleran acoso, discriminación, amenazas, doxxing, insinuaciones sexuales no deseadas, suplantación, spam, manipulación coordinada ni publicación de información privada. Tampoco se permite presionar a alguien para revelar datos de una explotación agrícola o credenciales de una instancia.

## Alcance y aplicación

Estas reglas rigen en repositorios, issues, pull requests, discusiones, eventos y espacios donde una persona represente al proyecto. Los mantenedores pueden editar o retirar contenido, cerrar interacciones, emitir advertencias o limitar la participación de forma proporcional y documentada.

Reporta incidentes en privado a `soporte@fundosmart.com` con el asunto `Conducta comunidad`. No abras un issue público. El equipo limitará el acceso al reporte, evitará represalias y responderá inicialmente dentro de siete días hábiles. Si el reporte involucra a quien normalmente lo recibiría, puede enviarse mediante un GitHub Security Advisory privado indicando que se trata de conducta, no de una vulnerabilidad.

Las decisiones pueden apelarse una vez aportando contexto nuevo. La persona que tomó la medida inicial no resolverá la apelación cuando exista otro mantenedor disponible.
